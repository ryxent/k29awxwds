Widgets

Widgets are sections made out of several components or sub widgets.

Standard vs Hero Widgets : Cards : Profile Box : Billboard : Carousel

Standard vs Hero Widgets

Standard Widgets are the the widgets that aren't supposed to take 100% width of the widget container.
Eg: Profile Box, Cards When you're creating your custom standard widgets, use the --gap token if you happen to use flexbox or grid within that widget.


Hero Widgets are the the widgets that are supposed to take 100% width (and sometimes the entire heigh too.) of the widget container.
Eg: Billboard, Carousel If you want to create a new hero widget, be sure to nullify the default padding by adding the following lines to your css file 

.widget:has(> .yourwidget) {
  padding: 0;
}

.yourwidget {
  padding: var(--wrap);
}
