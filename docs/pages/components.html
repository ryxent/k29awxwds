Components

Components are basic html and custom made single elements.

Native vs Custom Components : Images : Unordered Lists : Anchor Tags : Buttons : Input Fields : Option Selectors : Progress Bars : Typography

Native vs Custom Components

Native components are the default components you run into when using html. Eg: button, h1, h2, h3, h4, h5, h6, p, span, label...


Custom components are the non-native components that you may encounter when using k29awxwds.
Eg: progressbars

ImagesNative 

<img src="image.png" alt="Image">

  • Tokens: --nativecomponent-media-width | --nativecomponent-media-maxheight

Anchor TagsNative

Option 01: Open in the same tab:

<a href="#">Link <span class="xsm"><i class="ph-duotone ph-link-simple-break"></i></span></a>

Option 02: Open in new tab:

<a href="#" target="_blank">Link <span class="xsm"><i class="ph-duotone ph-arrow-square-out"></i></span></a>
  • Classes: None
  • Tokens: --text-action | --text-action-hover | --text-action-active | --text-disabled

Eg:

  • Default (--text-action): Link | Link
  • Default Option 01 (Open in the same tab): Link
  • Default Option 02 (Open in new tab): Link
  • Active State (--text-action-active): Link
  • Disabled State (--text-action-disabled): Link
