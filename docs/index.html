Getting Started

Add these required third-party dependencies and the core k29awxwds files to your project.

In your <head> tag:

<link rel="stylesheet" type="text/css" href="https://cdn.jsdelivr.net/npm/@phosphor-icons/web@2.1.1/src/duotone/style.css"/>
<link rel="stylesheet" href="k29awxwds/k29awxwds.css"/>

At the very end of your <body> tag: 

<script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/gsap.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/ScrollToPlugin.min.js"></script>
<script src="k29awxwds/k29awxwds.js"></script>

Baisc Layout

The layout uses the css grid. While you are free to get rif of the nav.nav or header.header zones, removing main.main, aside.rightbar or footer.footer blocks will break the rendering entirely.


Semantic Class Name (Required*) Optional?
header .header yes
nav .nav yes
main .main no (Required*)
aside .rightbar no (Required*)
footer .footer no (Required*)

Footer & Credits

While the footer credits are recommended to keep, you can remove them but doing so requires you to change the default layout background asset.


If you must remove them, be sure to swap the background gif. (/k29awxwds/assets/gif/bg.gif)

Page loader

Add this code block directly inside the body tag, before your layout container to activate the page loading progress bar. 

<div class="progresscontainer" id="pageloadcontainer">
  <div class="progressbar" id="pageloadbar"></div>
</div>

Cursor Circle

Place this in the same area as the pageloader progressbar to activate the 80px circle that follows the user's cursor. 

<div id="cursorcontainer">
  <div id="cursorcircle"></div>
</div>

Behavior Details:

  • Maintains a strict 150px gap buffer from the edges of the document.

  • Scales up by 1.4x automatically when hovering over interactive elements (like links or buttons).

Behavior Details:

  • Tokens: --core-cursorcircle-md | --core-cursorcircle-md
